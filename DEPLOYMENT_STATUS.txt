🔧 HOW TO FIX RAILWAY BACKEND:
================================================================================

STEP 1: Check Railway Dashboard
   - Go to: https://railway.app/dashboard
   - Select your project: cci-department-guidance-production
   - Check "Deployments" tab
   - Look for red X (failed deployment)

STEP 2: Check Logs
   - Click on the deployment
   - Check "Logs" tab
   - Look for error messages like:
     • "Module not found"
     • "Cannot find module"
     • "Port already in use"
     • "Database connection error"

STEP 3: Verify Environment Variables
   Go to Settings → Variables and ensure these are set:
   
   Required Variables:
   ✓ SUPABASE_URL=https://dztzjfqipllddyrrfcze.supabase.co
   ✓ SUPABASE_ANON_KEY=[your anon key]
   ✓ SUPABASE_SERVICE_ROLE_KEY=[your service role key]
   ✓ CORS_ORIGIN=https://cci-department-guidance.vercel.app
   ✓ NODE_ENV=production
   ✓ PORT=3000 (or leave empty - Railway auto-assigns)

STEP 4: Verify Build Settings
   Settings → Build:
   - Root Directory: backend (or leave empty if using railway.toml)
   - Build Command: npm install
   - Start Command: node src/server.js
   
STEP 5: Check railway.toml (if exists)
   File should be in project root with:
   [build]
   builder = "nixpacks"
   buildCommand = "cd backend && npm install"
   
   [deploy]
   startCommand = "cd backend && node src/server.js"
   restartPolicyType = "on_failure"
   restartPolicyMaxRetries = 3

STEP 6: Manual Redeploy
   - In Railway dashboard
   - Click "Deploy" button
   - Select "Redeploy"
   - Wait for deployment to complete
   - Check logs for success
