## Component Breakdown

```
App
├── Header (Purple gradient, always visible)
│
├── WelcomeScreen
│   ├── Introduction text
│   ├── Features list (4 items)
│   ├── Department tags (5 colored badges)
│   └── Start button (CTA)
│
├── AssessmentScreen
│   ├── ProgressBar (animated fill)
│   ├── QuestionCard
│   │   ├── Question text (h2)
│   │   └── Options (4-5 radio buttons styled as cards)
│   └── Navigation
│       ├── Previous button
│       └── Next button
│
├── ResultsScreen
│   ├── Title + subtitle
│   ├── RecommendationCard (x3)
│   │   ├── Rank badge (🥇🥈🥉)
│   │   ├── Department name
│   │   ├── Score bar (animated)
│   │   ├── Match reasons (bullet points)
│   │   └── Action buttons
│   └── Bottom actions
│       ├── Compare button
│       └── Retake button
│
└── ComparisonScreen
    ├── Department selector (checkboxes)
    ├── Comparison table (responsive)
    └── Export buttons (PDF, Print)
```

## Key Interactions

### Question Selection:
```
Default State: ┌─────────────┐
               │ ○ Option 1  │  (Light gray bg)
               └─────────────┘

Hover State:   ┌─────────────┐
               │ ○ Option 1  │  (Darker gray bg + shadow)
               └─────────────┘

Selected:      ┌─────────────┐
               │ ● Option 1  │  (Purple bg + white text)
               └─────────────┘
```


## Typography

```
Headers (h1):     32px, Bold, Purple
Subheaders (h2):  24px, Semibold, Dark Gray
Body text:        16px, Regular, Dark Gray
Button text:      16px, Semibold, White/Purple
Small text:       14px, Regular, Gray

Font Family: 'Inter' or 'Segoe UI' (system font)
```

## Responsive Breakpoints

```
Mobile:    < 640px   (Stack everything, full width)
Tablet:    640-1024  (2 columns where possible)
Desktop:   > 1024px  (3 columns, max-width 1200px)
```

## Animation Timing

```
Page transitions:      300ms ease-in-out
Button hover:          200ms ease
Progress bar fill:     500ms ease-out
Score bar animation:   1000ms ease-in-out
Card hover:            250ms ease
```

## Accessibility Features

- ✓ High contrast ratios (WCAG AA compliant)
- ✓ Keyboard navigation (Tab, Enter, Arrows)
- ✓ Screen reader labels (aria-labels)
- ✓ Focus indicators (visible outlines)
- ✓ Text alternatives for icons
- ✓ No time limits on questions
- ✓ Large tap targets (min 44x44px)
