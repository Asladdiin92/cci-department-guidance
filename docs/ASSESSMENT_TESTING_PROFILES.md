## TEST METHODOLOGY

For each sample student profile:
1. Define student characteristics and interests
2. Predict expected department match
3. Simulate answering all 20 questions
4. Calculate total scores
5. Verify correct department recommendation

**Scoring System**: 
- Strong match: 3 points
- Good match: 2 points  
- Weak match: 1 point
- No match: 0 points

**Maximum possible score per department**: 60 points (20 questions × 3 points)
