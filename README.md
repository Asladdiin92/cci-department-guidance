# CCI Department Choice Guidance System

This application helps students at Haramaya University's College of Computing and Informatics (CCI) identify the academic department that best aligns with their interests, skills, and career goals.

## Overview
Students complete a 20-question assessment about their preferences. Based on their responses, the system calculates compatibility scores and provides personalized department recommendations.

## Core Features
*   **Assessment Tool**: 20-question interactive survey.
*   **Recommendation Engine**: Real-time scoring system matching responses to specific departments.
*   **Side-by-Side Comparison**: Enables students to compare different CCI departments.
*   **Department Details**: Provides structured information about each department.
*   **Admin Dashboard**: A management interface for reviewing assessment data.

## Project Structure
*   `src/`: Contains the core application logic, styling, and data files.
*   `public/`: Contains HTML files for the application interfaces.
*   `assets/`: Contains images, icons, and logos.
*   `docs/`: Detailed project documentation and research.
*   `server.js`: Express server entry point to serve the application.

## How to Run
1.  Ensure you have Node.js installed.
2.  Install dependencies: `npm install`
3.  Start the development server: `npm run dev`
4.  Open the application in your browser at `http://localhost:3000`.
